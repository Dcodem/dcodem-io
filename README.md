# dcodem.io

Personal site for Dan Code-McNeil. Static HTML/CSS, deployed on Vercel.

## Local preview

Open `index.html` directly in a browser, or:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

Connected to Vercel — pushes to `main` deploy automatically.

## Headshot

Drop a square photo named `headshot.jpg` (recommend 400×400 or larger) at the repo root. If missing, the image element auto-hides.
